# Python - freeCodeCamp (v9)

Anotações, exercícios e projetos desenvolvidos durante o curso completo de Python da [freeCodeCamp](https://www.freecodecamp.org/learn/python-v9/).

## Sobre o curso

O curso Python v9 da freeCodeCamp cobre Python do zero ao avançado, com um projeto de certificação prático ao final de cada módulo principal. Todo o conteúdo é gratuito e baseado em projetos reais.

## Como executar

Certifique-se de ter Python 3 instalado:

```bash
python3 --version
```

Para rodar qualquer arquivo:

```bash
python3 caminho/para/arquivo.py
```
